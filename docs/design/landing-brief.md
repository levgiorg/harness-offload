# Surface brief — landing page (`site/index.html`)

Mode: Persuade. Audience: developers on a paid agent plan who run out of context/usage. Job: understand
the mechanism in seconds, trust it from real measurements, copy the install command for their harness.

## Direction contract
THESIS: The agent's context is a reading-room desk with little room; Harness Offload is the closed-stack
request service — send a slip, a runner reads the stacks, the answer comes back with its shelf marks
checked. Refuses the category default: a dark terminal hero with a neon install box.
OWN-WORLD: A committed carbon-copy blue field carries the page; on it lie printed request slips of
blue-white bond paper ruled in blue ink, field labels in condensed caps, filled-in fields typewritten,
and a single red rubber stamp for what was kept off the desk and what was verified. Perforations,
tear-off stubs, carbon duplicates.
STORY: See a real request travel (big file, noisy command, repo question), see the numbers it saved,
see which harness and plan it runs on, copy one command.
FIRST VIEWPORT: One wide request slip is the hero. Its printed title is the headline; its fields are the
live demo (request, intercepted, returned by, answer with checked shelf marks, stamp). A perforated
tear-off stub on its right edge (below it on phones) holds the harness picker and the install command
with Copy — the primary action. Nothing else competes.
FORM: Closed-stack library request slip (1st of 7 on the ordered list: request slip, pneumatic dispatch
capsule, shipping manifest, triage tag, flight strip, cue sheet, wire digest). Signature interaction:
switching the request type re-types the slip and presses the stamp once.
seed: none (unavailable)
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
