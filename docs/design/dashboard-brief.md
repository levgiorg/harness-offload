# Surface brief — local stats report (`offload dashboard`)

Mode: Operate. User: the developer checking whether offloading pays off and what is failing. Frequency:
occasional (after a day of work, when tuning models). Task: see tokens kept out of context, worker cost,
failures/cooldowns and citation quality; drill into recent delegations. Works offline (file://), no
network fonts or scripts.

## Direction contract
THESIS: A circulation desk report for one developer: what went out to the stacks, what came back, what
was kept off the desk. Refuses the default grey SaaS tile wall with a lone accent.
OWN-WORLD: The landing page's carbon-copy blue as the shell band, tinted blue-grey neutrals for panels,
system UI type, tabular numerals, the red stamp reserved for failures and unverified citations, green
for verified. Signature move: each delegation's citation result shown as a small verification stamp.
STORY: Summary first (kept off the desk, worker tokens, delegations, citations checked), then the daily
trend, then where it came from (by kind, by model), then the latest delegations.
FIRST VIEWPORT: Blue header band with the product name, period filter (1/7/30/all days) and the data
source path; one summary line of four figures; the daily chart below; tables follow.
FORM: Circulation report (operate: the world lends palette, density, type and the stamp move only).
seed: none (unavailable)
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
