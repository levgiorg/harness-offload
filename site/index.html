Out of the box, each harness reads with its own cheapest model. In Claude Code that is a lean claude -p with Haiku: no plugins, no MCP servers, a short system prompt of its own.

        
The saving is in your main session: the big material never enters its context, so the conversation stays short and every later turn costs less. Worker calls still count toward that plan’s limits, at the small model’s rate.

        
Run offload setup to pick other backends, add an API key or a local model, and choose a fallback.

      

    

  


  

    

      
Careful with your code

      

        
Fails open
If a backend is missing, slow or out of quota, the hooks step aside and your agent’s tools work as before.

        
Secrets stay home
.env, keys and certificates are never sent, links to them included, and credentials in output are masked.

        
Answers are checked
A citation must quote text within three lines of where it points. Anything else is marked unverified.
